# Mobile Workspace Instructions

This folder contains the Expo React Native mobile client for Chefo's Recipes.

- Visible mobile UI text should be in Bulgarian.
- Keep the mobile app focused on end-user recipe browsing and favorite-related functionality.
- Do not implement admin panel flows in mobile unless explicitly requested.
- The mobile app should consume the Next.js REST API later; keep future API integration in mind when shaping screens and data.
- Avoid adding navigation libraries unless explicitly requested.
- Keep local-state navigation and data flow simple until API integration is added.
- Keep mobile changes scoped to this app. Do not modify `apps/web`, `packages/db`, or `packages/shared` unless the task explicitly requires it.
- Do not add credentials, local `.env` files, or dependencies unless explicitly requested.
